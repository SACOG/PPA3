# Five-Minute Team Demo

Before the meeting, run `doctor.ps1`, start the harness, and keep one completed report available.

1. **Purpose (30 seconds):** explain that this is a local layer over unchanged PPA report services,
   using sandbox data and candidate lines instead of production submission and map drawing.
2. **Input fidelity (60 seconds):** switch between STIP, CMCP, ATP, and Federal. Point out fixed vs.
   selectable outcomes, Federal funding programs, candidate compatibility, and dispatch preview.
3. **Run behavior (60 seconds):** submit a small selection. Show immediate redirect, per-service
   pending/running/success/failure state, timing, and logs.
4. **Deliverable (90 seconds):** open a completed report. Show the project summary, specialized
   outcome cards, a generic service section with complete JSON, and an explicit failed section.
5. **Portability/safety (60 seconds):** show `setup.ps1`, `doctor.ps1`, and the local root. Emphasize
   read-only production sources, local candidate copy, isolated processes, and retained evidence.
6. **Handoff (30 seconds):** identify `README.md`, `ARCHITECTURE.md`, `live_contract.json`, and the
   run-history page as the starting points for the next maintainer.
